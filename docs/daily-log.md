# 日々の記録

ゲームや絵など、その日に行った活動を一つのページにまとめます。ソースは `daily/YYYY-MM-DD.md`、生成先は `log/YYYY-MM-DD.html` です。`log.html` には活動時間に応じた年間グラフと最近の記録が表示されます。

## ブラウザから編集する

次のコマンドを実行すると、ローカル専用の編集フォームがブラウザで開きます。

```sh
npm run daily:edit
```

フォームでは次の操作ができます。

- 日付、タイトル、概要の入力
- 一日に行った複数の活動の追加と削除
- カテゴリー、活動名、活動時間、成果や課題の入力
- 15分から3時間までの時間プリセットと自由入力
- 活動時間の合計とカテゴリーの自動計算
- 既存記録の読み込みと更新
- 保存後の公開用HTMLの自動生成

終了するには、起動したターミナルで `Ctrl+C` を押します。

編集サーバーは `127.0.0.1:4173` だけで待ち受け、公開サイトには含まれません。ポートを変更する場合は `DAILY_EDITOR_PORT` を指定します。

```sh
DAILY_EDITOR_PORT=5000 npm run daily:edit
```

## 雛形を直接編集する

JSTの当日の日付を使った雛形を作成します。

```sh
npm run new-daily
```

日付を指定する場合は `YYYY-MM-DD` 形式で渡します。

```sh
npm run new-daily -- 2026-09-02
```

雛形は `templates/daily.md` です。生成されたMarkdownのfront matterには、その日の合計活動時間とカテゴリーを記入します。

```md
---
date: 2026-09-02
title: 2026-09-02の記録
minutes: 180
categories: ゲーム, 絵
---
```

- `date` は必須で、ファイル名と一致させます。
- `minutes` は0以上の整数です。年間グラフの色分けに使われます。
- `categories` はカンマ区切りで記述します。
- 本文では活動ごとに見出しを作り、不要な項目は削除できます。

ブラウザの編集フォームで作成したMarkdownの末尾には、再編集用の `daily-editor` メタデータが自動的に追加されます。この行は公開HTMLには出力されないため、直接削除しないでください。

## 生成

```sh
npm run build
```

このコマンドで年間活動グラフを含む `log.html` と日別ページ `log/*.html` が生成されます。生成されたHTMLは直接編集しないでください。

年間グラフの色は、その日の合計活動時間に応じて次のように変わります。

| レベル | 活動時間 |
| --- | --- |
| 0 | 記録なし、または0分 |
| 1 | 1〜30分 |
| 2 | 31〜60分 |
| 3 | 61〜120分 |
| 4 | 121分以上 |
