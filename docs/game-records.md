# 趣味ページ

`games.html` は「趣味」ページです。ゲーム・アニメ・漫画・VTuberを同じカード一覧に掲載します。既存リンクとゲームのアンカーを維持するため、URLは変更していません。

ゲーム記録には、ゲームごとの目標、進捗、実績、プレイ頻度を掲載します。アニメの作品・コメントは本人が指定した内容だけを追加します。アニメが未登録の場合は、アニメの絞り込み時に空状態を表示します。

## 更新方法

ゲーム記録の内容は `games.html` を直接編集します。ただし、`component:sidebar` マーカーで囲まれたサイドバーは自動生成されるため編集しないでください。

主な表示要素は次のとおりです。

- 高頻度、たまに、休止中のプレイ状況
- スキル値と目標までの進捗バー
- 段位や作品ごとの達成表
- 達成履歴
- TA、RTAの記録
- 外部の記録サービスへのリンク

概要は常時表示し、達成表や履歴はカード全体のクリック、またはカードにフォーカスしてEnter・Spaceキーで背景に一覧が見える拡大カードで開きます。「一覧に戻る」、Escキー、背景クリック、ブラウザの「戻る」で詳細を閉じ、元のカード位置へ戻ります。ブラウザの「進む」では詳細を再表示します。初期表示では区切り見出しを設けず、すべてのカードをマソンリーレイアウトで掲載します。

ページ幅・余白・書体・見出しは他ページと同じ `style.css` の共通スタイルを使います。カードやフィルター、拡大表示の見た目は `games.css`、フィルターとモーダルの開閉は `games.js` で管理します。PCでは高さの異なるカードを2列に詰め、スマートフォンでは1列になります。カードは列の上から下へ読み進める順序です。横長の表はモーダル内で横スクロールできます。JavaScriptが無効な場合はフィルターを隠し、すべてのカードを表示して詳細はカード内の折りたたみ表示に戻ります。

「すべて・ゲーム・アニメ・漫画・VTuber」のタグで絞り込みます。複数タグがあるカードは各タグの絞り込みに表示します。ゲーム内ジャンルとプレイ頻度はデータとして保持し、絞り込みには使用しません。プレイ頻度はカード上に表示します。「絞り込みを解除」で全件に戻ります。表示件数は自動集計します。

カードは同じ `#game-records` 内に追加し、空白区切りの `data-tags`（例：`game`、`anime manga`、`vtuber`） と一意の `id` を指定します。`.record-header h3` に作品名または人物・グループ名、`.record-caption` に本人が指定した好きなところを短く置きます。好きな理由が未指定の場合は既存記録の事実要約を使い、好みを創作しません。ゲームの記録概要は `.record-overview` に保持して拡大先へ表示します。追加の詳細がある場合は `.record-details > .record-detail-body` を使用します。タグを問わず同じ拡大表示を利用でき、記述順を維持します。

ゲームカードの `data-genre` は `rhythm`（音楽ゲーム）、`stg`（シューティング）、`speedrun`（TA / RTA）、`online`（オンライン / MMO）のいずれかを指定します。`data-frequency` は `frequent`、`occasional`、`paused` を指定し、カード内のプレイ頻度ラベルと揃えてください。

記録を更新する際は、詳細表とカード上部の概要・目標・更新日を合わせて更新してください。カード追加時は冒頭と初期表示の件数も更新します。JavaScript有効時は種類別の件数を自動集計します。未入力の更新日は表示しません。

`games.css` と `games.js` を変更した際は、`games.html` の読み込みURLの `v` も更新してキャッシュを更新します。

GITADORAのSkill推移グラフのデータと描画処理は `chart.js` で管理しています。

更新後は共通コンポーネントとメタ情報を反映するため、サイトをビルドします。

```sh
npm run build
```
