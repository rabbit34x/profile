# ゲーム記録

`games.html` には、ゲームごとの目標、進捗、実績、プレイ頻度を掲載します。

## 更新方法

ゲーム記録の内容は `games.html` を直接編集します。ただし、`component:sidebar` マーカーで囲まれたサイドバーは自動生成されるため編集しないでください。

主な表示要素は次のとおりです。

- 高頻度、たまに、休止中のプレイ状況
- スキル値と目標までの進捗バー
- 段位や作品ごとの達成表
- 達成履歴
- TA、RTAの記録
- 外部の記録サービスへのリンク

概要は常時表示し、達成表や履歴はカード全体のクリック、またはカードにフォーカスしてEnter・Spaceキーで背景に一覧が見える拡大カードで開きます。「一覧に戻る」、Escキー、背景クリック、ブラウザの「戻る」で詳細を閉じ、元のカード位置へ戻ります。ブラウザの「進む」では詳細を再表示します。初期表示では区切り見出しを設けず、すべてのカードをマソンリーレイアウトで掲載します。

ゲーム記録ページ専用の見た目は `games.css`、フィルターとモーダルの開閉は `games.js` で管理します。PCでは高さの異なるカードを2列に詰め、スマートフォンでは1列になります。カードは列の上から下へ読み進める順序です。横長の表はモーダル内で横スクロールできます。JavaScriptが無効な場合はフィルターを隠し、すべてのカードを表示して詳細はカード内の折りたたみ表示に戻ります。

ジャンルとプレイ頻度はそれぞれ1つずつ選択でき、両方の条件に合うカードを表示します。「絞り込みを解除」で全件に戻ります。表示件数は自動集計します。

カードの `data-genre` は `rhythm`（音楽ゲーム）、`stg`（シューティング）、`speedrun`（TA / RTA）、`online`（オンライン / MMO）のいずれかを指定します。`data-frequency` は `frequent`、`occasional`、`paused` を指定し、カード内のプレイ頻度ラベルと揃えてください。

記録を更新する際は、詳細表とカード上部の概要・目標・更新日を合わせて更新してください。ゲームの追加やプレイ頻度の変更時は冒頭の件数も更新します。未入力の更新日は表示しません。

GITADORAのSkill推移グラフのデータと描画処理は `chart.js` で管理しています。

更新後は共通コンポーネントとメタ情報を反映するため、サイトをビルドします。

```sh
npm run build
```
