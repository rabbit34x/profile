# ゲーム記録

`games.html` には、ゲームごとの目標、進捗、実績、プレイ頻度を掲載します。

## 更新方法

ゲーム記録の内容は `games.html` を直接編集します。ただし、`component:sidebar` マーカーで囲まれたサイドバーは自動生成されるため編集しないでください。

主な表示要素は次のとおりです。

- 高頻度、たまに、休止中のプレイ状況
- スキル値と目標までの進捗バー
- 段位や作品ごとの達成表
- 達成履歴
- TA、RTAの記録
- 外部の記録サービスへのリンク

GITADORAのSkill推移グラフのデータと描画処理は `chart.js` で管理しています。

更新後は共通コンポーネントとメタ情報を反映するため、サイトをビルドします。

```sh
npm run build
```
