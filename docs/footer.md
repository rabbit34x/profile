# 共通フッター

各ページのフッターには、最終更新日時とGitコミットハッシュを表示します。

- 最終更新日時は、ブラウザが取得したページの `Last-Modified` をJSTで表示します。
- コミットハッシュは、ビルドで生成される `site-meta.js` から表示します。
- 短縮ハッシュは、GitHubの該当コミットへのリンクになります。

## ローカルビルド

ローカルでは現在のGit HEADを使用します。

```sh
npm run build
```

## CIでのビルド

`GITHUB_SHA` が設定されている場合は、その値を優先します。公開するコミットのハッシュを正しく表示するため、デプロイ前にビルドしてください。

```sh
GITHUB_SHA=<commit-hash> npm run build
```
