# ギャラリー

## 画像の追加

元画像をカテゴリーに対応するフォルダへ追加します。

```text
gallery-src/
├── ff14/    # FF14のスクリーンショット
├── games/   # ゲームのスクリーンショット
├── dolls/   # ドールの写真
├── imas/    # アイドルマスター関連の画像
└── photos/  # 通常の撮影写真
```

対応形式は `.jpg`、`.jpeg`、`.png`、`.webp`、`.heic` です。ファイル名からキャプションを生成するため、内容が分かる名前を付けてください。ハイフンとアンダースコアは空白として表示されます。

```text
gallery-src/games/ff14-絶エデン.jpg
gallery-src/dolls/夏服コーデ.jpg
gallery-src/imas/ライブ衣装.jpg
gallery-src/photos/夕暮れの海.jpg
```

## 並び順

FF14以外のカテゴリー内の画像は、EXIFの撮影日時が新しい順に表示されます。EXIFに撮影日時がない場合はファイル名に含まれる日時を使用し、どちらからも取得できない画像は末尾へファイル名順で表示します。

### FF14のサブカテゴリ

FF14の分類と表示順は `gallery-src/ff14/groups.json` で管理します。配列の順番がサブカテゴリの順番、各項目の `images` の順番が画像の順番です。日時による自動並べ替えは行いません。

- `id`: 重複しない英小文字・数字・ハイフンの識別子
- `title`: 「絶バハムート」「絶エデン 2ndシーズン」などの表示名。初回のシーズン表記は省略します。
- `images`: `gallery-src/ff14/` 内の元画像ファイル名の配列

画像を追加したら、対応するサブカテゴリの `images` にも追加してビルドします。画像の重複登録、存在しないファイル、未分類の画像はビルドエラーになります。生成された見出しや画像部分は直接編集しないでください。

ギャラリーでは全サブカテゴリと画像を指定順で表示します。

## 生成と画像最適化

画像を追加したらビルドします。

```sh
npm run build
```

ビルド時に次の処理を行います。

- 表示用画像を最大幅1600px、品質82のWebPへ変換
- サムネイルを最大幅480px、品質78のWebPへ変換
- EXIFなどの画像メタデータを削除
- `gallery.html` のFF14、ゲーム、ドール、アイマス、写真の各欄を自動更新

生成画像は `images/gallery` に出力されます。このフォルダ内のファイルと、`gallery.html` 内の `gallery:*` マーカーで囲まれた部分は直接編集しないでください。
