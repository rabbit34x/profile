# Profile

- [ビルド](docs/build.md) — 依存関係のインストールとサイト全体の生成
- [共通コンポーネント](docs/components.md) — サイドバーとナビゲーションの一元管理
- [ゲーム記録](docs/game-records.md) — 目標、進捗、実績、プレイ頻度の表示
- [アカウント一覧](docs/accounts.md) — 外部サービスへのリンク管理
- [ブログ](docs/blog.md) — Markdownによる記事の作成
- [動画・SNS投稿の埋め込み](docs/media-embeds.md) — YouTubeとTwitter/Xの埋め込み
- [日々の記録](docs/daily-log.md) — 活動記録、年間グラフ、ローカル編集フォーム
- [ギャラリー](docs/gallery.md) — 画像の追加、変換、並び順
- [トップ画像](docs/home-image.md) — トップ画像の最適化
- [共通フッター](docs/footer.md) — 最終更新日時とGitコミットの表示
